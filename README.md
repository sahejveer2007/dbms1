# Internship Portal

Database: `job_internship_portal` | MySQL user: `root` | Password: `Rohit55biradar` (set in `.env`)

## Run
1. Start MySQL.
2. Windows: double-click `start.bat`. Mac/Linux: `./start.sh`.
   Or in a terminal opened INSIDE this folder: `npm install` then `npm start`.
3. The browser opens by itself. If not, open the address printed in the terminal ("WEBSITE READY -> ...").
   If port 3000 is busy, the project automatically uses 3001, 3002, ...

Needs: Node.js (nodejs.org) and MySQL. The database and demo data are created automatically.
